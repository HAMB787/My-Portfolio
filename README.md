# 🚀 Professional Data Portfolio

Welcome to my professional portfolio. I specialize in **Data Analytics** and **Data Engineering**, building robust data pipelines, extracting insights through advanced SQL and BI tools, and developing AI-powered data applications.

## 📂 Portfolio Structure

This repository is organized into distinct categories based on the data discipline:

### 📊 Data Analyst Projects (`/data-analyst`)
Projects focused on data querying, modeling, and visualization to extract business insights.
- **[Pizza Sales Analysis](./data-analyst/pizza-sales-analysis/)** — End-to-end SQL analysis and Power BI dashboarding for a pizza retail dataset.
- **[Power BI Dashboards](./data-analyst/power-bi-dashboards/)** — A collection of advanced Power BI dashboards covering Finance (Ameria Bank), Retail (Maven Markets), and NGO domains.

### ⚙️ Data Engineering Projects (`/data-engineering`)
Projects focused on building scalable ETL/ELT pipelines, data warehousing, and backend data systems.
- **[Residential Real Estate Pipeline](./data-engineering/real-estate-residential-pipeline/)** — Comprehensive Python scraper → ClickHouse → dbt → Power BI pipeline.
- **[Commercial Real Estate Pipeline](./data-engineering/real-estate-commercial-pipeline/)** — Scraper to Streamlit dashboard pipeline with daily upsert logic.
- **[dbt Analytics Warehouse](./data-engineering/dbt-analytics-warehouse/)** — Professional dbt project featuring staging, marts, looker, and reporting layers.
- **[LinkedIn Job Market Scraper](./data-engineering/linkedin-job-market-scraper/)** — Async Playwright stealth scraper with smart regex filtering and salary normalization.
- **[Manufacturing ERP System](./data-engineering/manufacturing-erp-system/)** — Full-stack system featuring a MySQL database with complex triggers/stored procedures, FastAPI backend, and Streamlit frontend.

### 🤖 AI Agents & Bots (`/TelegramBOT`)
- **[AI Data Analyst Telegram Bot](./TelegramBOT/)** — An intelligent bot that accepts CSV uploads and answers natural language questions using an LLM and sandboxed Pandas execution.

### 🎓 Academic & Algorithms (`/University`)
- Algorithms and academic coursework covering optimization methods, machine learning, and dynamic programming (e.g., non-linear transportation problem).
