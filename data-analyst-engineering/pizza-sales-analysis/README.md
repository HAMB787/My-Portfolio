# 🍕 Pizza Sales Analysis

An end-to-end data analysis project exploring pizza sales data using **SQL** for deep-dive querying and **Power BI** for interactive dashboard visualization.

---

## 📋 Overview

This project analyzes a pizza sales dataset (~50 K+ transactions) to extract actionable business insights. The analysis covers revenue trends, best/worst sellers, order patterns by day and time, and category-level performance.

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| **SQL** | Data querying, aggregation, KPIs |
| **Power BI** | Interactive dashboard & visualizations |
| **CSV** | Raw data source |

## 📂 Project Files

| File | Description |
|---|---|
| `pizza_sales_queries.sql` | SQL queries for key business metrics (revenue, avg order value, top/bottom sellers, daily/monthly trends) |
| `pizza_sales_report.pbix` | Power BI dashboard with interactive filters and visualizations |

## 📊 Key Metrics Analyzed

- **Total Revenue** & **Average Order Value**
- **Total Pizzas Sold** & **Total Orders**
- **Daily & Monthly Trends** — identifying peak days and months
- **Sales by Category & Size** — percentage contribution analysis
- **Top 5 & Bottom 5 Sellers** — by revenue, quantity, and total orders

## 🚀 How to Use

1. Open `pizza_sales_queries.sql` in any SQL client to run the analysis queries
2. Open `pizza_sales_report.pbix` in Power BI Desktop to interact with the dashboard
