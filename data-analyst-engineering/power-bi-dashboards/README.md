# 📊 Power BI Dashboard Collection

A curated set of **Power BI** dashboards built for different industries and business domains — demonstrating data modeling, DAX calculations, and interactive visualization skills.

---

## 📂 Dashboards

### 1. Ameria Bank Analysis (`ameria_analysis.pbix`)
- **Domain:** Banking & Finance
- **Focus:** Financial performance metrics, customer segmentation, and trend analysis for Ameria Bank
- **Skills:** DAX measures, financial KPIs, time-intelligence functions

### 2. Maven Markets (`maven_markets.pbix`)
- **Domain:** Retail & E-commerce
- **Focus:** Multi-store retail analytics — sales performance, product mix, customer behavior across markets
- **Skills:** Star schema data modeling, drill-through reports, geographic analysis

### 3. Teach for Armenia Analysis (`teach_for_armenia_analysis.pbix`)
- **Domain:** Education / NGO
- **Focus:** Program effectiveness metrics and impact analysis for the Teach for Armenia initiative
- **Skills:** KPI dashboards, comparative analysis, storytelling with data

---

## 🛠️ Tech Stack

- **Power BI Desktop** — Data modeling, DAX, visualizations
- **Power Query (M)** — Data transformation & cleaning

## 🚀 How to Use

Open any `.pbix` file in **Power BI Desktop** (free download from Microsoft) to explore the interactive dashboards.
